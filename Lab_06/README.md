# Лабораторна робота №6 (Варіант 11: Логування викликів функцій)

Цей репозиторій містить реалізацію HOF (Higher-Order Functions), замикань та параметризованих декораторів.

## Реалізовані компоненти:
- **Замикання**: `make_logger` (чиста ін'єкція) та `make_counter` (змінний стан через `nonlocal`).
- **Декоратори**: Фабрики декораторів `@timed` (вимірювання часу) та `@logged` (логування аргументів, результатів і винятків).
- Композиція декораторів представлена у `main.py`.
